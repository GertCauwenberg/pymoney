# PyMoney File Codemap

**Last Updated:** 2026-10-13
**Entry Points:** `server/src/pymoney/api/app.py`, `desktop/src/pymoney_desktop/__main__.py`, `frontend/apps/web/src/main.tsx`, `run.sh`

A directory-by-directory map of what lives where. Module APIs are in
[MODULES.md](MODULES.md); the system view is in [ARCHITECTURE.md](ARCHITECTURE.md).

## Top Level

```
pymoney/
├── Makefile                  # delegates to the three components + i18n-check + compose
├── AGENTS.md                 # contributor/agent guide: commands, generated files, gotchas
├── README.md                 # the long guide: 14 design decisions, persistence, importers
├── run.sh                    # starts the API + Vite dev server together
├── compose.yaml              # dev stack (PostgreSQL); compose-production.yaml for deploy
├── .env.example              # every PYMONEY_* / POSTGRES_* variable, documented
├── scripts/                  # i18n.py + string-wrapping helpers (repo-wide)
├── docker/postgres/initdb.d/ # creates the test database on first boot
├── build/pyinstaller/        # desktop freeze config (pymoney-desktop)
├── dist/                     # build output
├── attachments/              # local attachment blobs (dev data, not source)
└── docs/CODEMAPS/            # these files
```

server/

└── src/pymoney/

    ├── core/             # pure domain (see MODULES.md)
    │   ├── book.py           # Book: queries, execute, bulk, revision
    │   ├── commands.py       # command dataclasses + CommandResult + fingerprint
    │   ├── handlers/         # per-aggregate command handlers
    │   ├── transaction.py, posting.py, split logic
    │   ├── amount.py, rounding.py, commodity.py
    │   ├── price.py, reports.py

    │   ├── schema.py         # ledger tables

    │   ├── attachments.py, grants.py, import_mappings.py, admin.py
    │   ├── migrate.py        # `python -m pymoney.store.migrate` (no alembic.ini needed)

    ├── importers/
    │   ├── kmymoney/     # parser.py, model.py, importer.py, report.py, __main__.py

    │   ├── views.py          # read models (shared with desktop offline)

    │                         # reports, schedules, csv_import, sync, quotes, _shared

## Generated Files — do not hand-edit

| File | Regenerate with | Enforced by |
|------|-----------------|-------------|
| `server/docs/openapi.json` | `make -C server openapi` | CI fails on drift |
| `frontend/packages/core/src/generated/openapi.d.ts` | `npm run generate` (`frontend/`) | `npm run check` |
| `frontend/packages/core/src/generated/nl.json` | `scripts/i18n.py` | `make i18n-check` |
| `server/src/pymoney/store/migrations/versions/*` | Alembic autogenerate | reviewed by hand; mypy-excluded |

## Key Files Cheat Sheet

| I want to… | Start at |
|------------|----------|
| Understand the domain rules | `server/src/pymoney/core/commands.py`, `transaction.py` |
| Change a wire field | `server/src/pymoney/api/schemas.py` → regenerate openapi + TS |
| Add an API endpoint | `server/src/pymoney/api/routers/` + `api/views.py` |
| Change the DB schema | `server/src/pymoney/store/schema.py` + new Alembic revision |
| Add a report | `server/src/pymoney/core/reports.py` → `api/views.py` → frontend `reports/` |
| Fix money rounding | `server/src/pymoney/core/rounding.py`, `tests/test_posting.py` |
| Add a translation | `server/src/pymoney/i18n/nl.json` via `scripts/i18n.py` |
| Run everything locally | `make install && run.sh` |
